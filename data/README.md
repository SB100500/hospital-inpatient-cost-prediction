# Dataset

This project uses the **Hospital Inpatient Discharges (SPARCS De-Identified)** dataset from the New York State Department of Health.

## Dataset Description

The dataset contains inpatient hospital discharge records with information related to:

- Patient demographics
- Admission characteristics
- Diagnoses and procedures
- Clinical severity and risk of mortality
- Source of payment
- Total hospital charges and costs

## Source

**New York State Open Data – Hospital Inpatient Discharges (SPARCS De-Identified)**

https://health.data.ny.gov/

## Usage

The dataset is used in this project for:

- Exploratory data analysis
- Feature engineering
- Hospital inpatient charge prediction
- Model evaluation and business insights

The dataset included in this repository is the same dataset used for the analysis.
